## 4. Решения, принятые без команды (подробно — PROGRESS.md, раздел «Решения»)
- Даты: код сначала разбирает сказанное (raw); type/value от модели — только запасной путь.
  Не распознано → флаг unparsed, дата не выдумывается.
- «В следующую пятницу» = пятница СЛЕДУЮЩЕЙ недели. «Через месяц», «утром» — unparsed.
- «Мастер приедет завтра с 10 до 14»: срок = завтра, окно времени остаётся в тексте срока.
- Цитаты: обязательство подтверждено, только если найдены ВСЕ его цитаты; пересказ не проходит.
  Цитаты короче 5 символов не подтверждаются. Цифры сравниваются как слова (5000 = «пять тысяч»).
- Эталон: id вида call_001_c2; даты в эталоне написаны руками, не кодом.
- Запись стерео: хлопок при лежащих РЯДОМ диктофонах, потом разойтись по комнатам (в наушниках).
