## 4. Решения, принятые без команды (подробно — PROGRESS.md, раздел «Решения»)
- Дату звонка модели не передаём: срок она отдаёт словами, дату считает код.
- Статус «replaced» ставит только код по ссылке replaces. Условие при firm → conditional.
- Ответ модели: json_schema → json_object → без формата (что примет сервер); один повтор при
  невалидном JSON, дальше ошибка. <think>…</think> от Qwen3 вырезается.
- Закрытия: только по обязательствам из звонков РАНЬШЕ текущего; цитата обязана найтись в новом
  звонке и быть не короче 10 символов / 2 слов; одно предложение на обязательство.
- Повторный прогон звонка заменяет его результаты (и стирает решения человека по ним).
- Если старый звонок загружен позже нового, новый надо прогнать ещё раз, иначе закрытий не будет.
- id в хранилище — c_0001…, в эталоне — call_001_c2 (сопоставляются по содержанию).
- Даты (с прошлого запуска): «в следующую пятницу» = пятница следующей недели; «через месяц»,
  «утром» — unparsed; цитаты: обязательство подтверждено, только если найдены ВСЕ его цитаты.
