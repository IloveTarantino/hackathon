  Evidence.speaker/t могут быть null, если цитата не найдена (verified=false).

  расставляется детерминированно, speaker/t цитат берутся из расшифровки. Правка датасета = правка скрипта + перезапуск.

- (T03) «Мастер приедет с 10 до 14»: окно времени остаётся в deadline.raw и в action, тип срока — tomorrow (в контракте
  нет времени суток). «29-го», сказанное 29-го → следующий месяц + same_day_of_month.
- (T03) Отказ (declined) оформлен как обязательство клиента со статусом declined и цитатой отказа.
- (T03) Синхронизация живых записей: хлопок при лежащих РЯДОМ диктофонах до того, как разойтись по комнатам
  (в наушниках чужой хлопок в свой микрофон не попадёт). Сверх задачи — scripts/make_stereo.py (автопоиск хлопка,
  склейка в стерео 8 кГц A-law, короткий канал дополняется тишиной).
- (T04) Порядок в dates.resolve(): сначала код разбирает сырой текст срока (raw); type/value от модели используются,
  только если raw разобрать не удалось; иначе флаг unparsed. Сказанное важнее типа от модели (маленькая модель путает типы).
- (T04) Не распознано → type=none + флаг unparsed, raw сохраняется, дат нет (ничего не выдумываем).
- (T04) «В следующую пятницу» и «на следующей неделе в пятницу» → пятница СЛЕДУЮЩЕЙ недели (без флага). «На этой неделе
  в пятницу», сказанное в пятницу → сегодня. Трактовка спорная, при желании поменять в dates._parse_raw.
- (T04) Числа, которого нет в месяце («до тридцать первого» 31 октября) → ближайший месяц, где оно есть (31.12).
- (T04) Явная дата, равная дню звонка → сегодня, без флага. «29 февраля» → ближайший високосный год.
- (T04) Сверх правил: «в течение N дней/недели» → интервал от дня звонка; «через час», «к вечеру», «до конца дня» →
  today; «до конца следующей недели/месяца» (value="next"); «до конца года» → explicit_date 31.12.
  «Через месяц», «утром», «в мае», «в следующем квартале» → unparsed (типа для них в контракте нет).
- (T04) Цифры «с 10 до 14» считаются часами, а не числами месяца. Два дня недели в одной фразе → берётся первый.
- (T05) Оценка совпадения = partial_ratio × min(1, длина фразы / длина цитаты): без штрафа короткая фраза «да»
  «подтверждала» бы любую цитату со словом «да». Цитаты короче 5 символов не подтверждаются вообще.
- (T05) Перед сравнением цифры переводятся в слова («5 000» → «пять тысяч», «10%» → «десять процентов»): модель
  может записать число цифрами, а в расшифровке ASR оно словами.
- (T05) Склейка: до 3 соседних фраз подряд и до 3 фраз одного говорящего (через чужое «угу»). Одна фраза
  предпочитается склейке (склейка должна быть лучше на 3 балла). Время и автор — от фразы, где цитата начинается.
- (T05) verified = найдены ВСЕ цитаты обязательства. Пересказ вместо цитаты (балл ~70) не подтверждается — это
  намеренно строго; порог quotes.THRESHOLD = 85.
- (T06) Два вида бэкендов: OpenAI-совместимый отвечает на промпт (chat_json), mock отвечает сразу «сырым» JSON
  (extract/closures) в том же виде, что и модель: без дат, времени и авторов цитат. Пост-обработка у них общая.
- (T06) mock отдаёт эталон, только если call_id есть в data/gold И все цитаты эталона дословно есть в расшифровке;
  иначе эвристика (живой звонок с именем call_001 не получит чужие обязательства).
- (T06) Эвристика mock (llm.heuristic_extract) — заглушка: глаголы 1-го лица будущего времени + срок, понятный
  dates.py; суммы не извлекает, действие = инфинитив + предмет из короткого списка. Для демо НЕ годится.
- (T06) Статус «replaced» ставит только код (по ссылке replaces от модели). Условие при статусе firm → conditional.
  Кредитор, если модель не дала/дала чепуху: сотрудник↔клиент; для третьего лица — собеседник автора цитаты.
- (T06) Дату звонка модели НЕ передаём (чтобы не считала даты сама). Модели ответа мягкие (лишние поля, "null"
  строкой, неизвестный type срока не вызывают повтор); схема для response_format — строгая (llm.strict_schema).
- (T06) response_format: json_schema → при 400/404/422/501 json_object → без формата; рабочий режим запоминается.
  Из ответа вырезается <think>…</think> (Qwen3) и ```-обёртка. Новая настройка LLM_TIMEOUT (300 с).

- (T07) Предложение закрыть отбрасывается, если: id не из списка кандидатов, цитата не найдена в новом звонке,
